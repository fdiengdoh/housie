About This App

This app replaces the physical board and balls, so you only need physical tickets. Tap the icon (or press Spacebar) to draw a number between 1–90.

Tap the Played counter badge anytime to inspect the exact order in which numbers were called to verify claims.

This app is built purely with HTML, CSS, and vanilla JavaScript, using Local Storage to save your progress automatically.

To start fresh, tap the icon. This will delete previous game progress!

Enjoy!!
